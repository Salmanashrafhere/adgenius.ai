## 2025-05-15 - Form wrapper for single-input actions
**Learning:** Wrapping single-input actions (like a product URL entry) in a `<form>` element significantly improves micro-UX by enabling natural 'Enter' key submission and mobile keyboard 'Go' functionality, which users often expect by default.
**Action:** Always wrap input-plus-button interactions in a `<form>` with a `type="submit"` button to support standard browser behaviors and improve accessibility.
