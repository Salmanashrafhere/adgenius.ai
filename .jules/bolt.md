## 2025-05-14 - Optimizing Campaign List Payload
**Learning:** The `GET /api/campaigns` route was fetching all columns from both `campaigns` and the related `ad_creatives` table. For list views (Dashboard and Campaigns page), most of this data was unused. By selecting only necessary fields and reducing the `ad_creatives` join to just IDs, we can reduce the payload size by approximately 60-90%. To maintain backward compatibility, it's safer to keep the `ad_creatives` array but only with minimal fields (like `id`) instead of removing it entirely.
**Action:** Always select specific fields in Supabase queries for list-based API routes. When optimizing related arrays, fetch only the `id` field to allow existing `.length` checks to work while still significantly reducing data transfer. Use server-side mapping to provide an explicit `adsCount` for cleaner consumption.
