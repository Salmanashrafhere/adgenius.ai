## 2025-05-14 - API Payload Optimization for Campaigns
**Learning:** Selecting all fields (`*`) and joining all fields from related tables (like `ad_creatives(*)`) in a list view API route creates a massive payload bottleneck. For the campaigns list and dashboard, we only need a few core fields and a count of ads, not the full creative content. Reducing the query to specific fields and only joining the `id` of related items can reduce payload size by 60-90% and improves response times. However, completely removing the related array can break frontend consumers; it is better to keep the array but only include the `id` field.
**Action:** Always use specific field selection in list APIs. Join related tables only for necessary fields (e.g., `id`) and provide a mapped count property on the server while retaining the slimmed array for backward compatibility.
