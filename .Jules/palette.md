## 2026-05-24 - [Global Search & Escape Handling]
**Learning:** Adding a global search shortcut (`/`) significantly improves power-user efficiency, while a visual `<kbd>` hint ensures discoverability for all users. Pair this with `Escape` key listeners on all persistent dropdowns (notifications, profile) to provide a consistent "undo/close" pattern.
**Action:** Always implement `Escape` key handling for custom dropdowns and consider standardized keyboard shortcuts for primary actions (Search, New Item).
