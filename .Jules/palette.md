## 2025-06-15 - Global Navigation UX & Accessibility

**Learning:** Global search shortcuts (like `/`) significantly improve power-user efficiency, while semantic elements in dropdowns (using `button` for actions) ensure the application remains accessible to screen reader and keyboard-only users.

**Action:** Always pair icon-only or hidden-shortcut features with discoverable visual cues (like `<kbd>`) and ensure all interactive list items use appropriate semantic roles or elements.
