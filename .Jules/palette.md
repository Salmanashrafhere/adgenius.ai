## 2025-01-24 - Search Keyboard Accessibility
**Learning:** Adding a keyboard shortcut like `/` for search significantly improves the power-user experience and aligns with modern SaaS patterns (e.g., GitHub, Slack). Pairing the shortcut with a visible `<kbd>` hint ensures discoverability for all users.
**Action:** Always include keyboard shortcuts for primary global actions (search, navigation) and provide corresponding visual hints.
