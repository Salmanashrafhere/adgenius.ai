## 2024-12-31 - Global Navigation & Keyboard Accessibility

**Learning:** Pairing keyboard shortcuts (like `/` for search) with discoverable visual cues (like `<kbd>`) significantly improves power-user efficiency while keeping the UI clean. Additionally, ensuring dropdown items are semantic `button` elements rather than `div` tags is crucial for screen reader compatibility and keyboard tab navigation.

**Action:** Implement global search shortcuts and refactor interactive dropdown items to semantic elements in the `Header` component.
